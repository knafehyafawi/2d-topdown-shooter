# 2D Top-Down Shooter

This is a 2D top-down shooter made using the Godot engine 4.6.2.

I am following a tutorial on YouTube on how to make a 2D top-down shooter, but since the tutorial is outdated and I want to scale, I am adding my own stuff too. The tutorial can be viewed here: https://www.youtube.com/watch?v=HycyFNQfqI0
