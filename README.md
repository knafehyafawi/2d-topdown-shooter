# 2D Top-Down Shooter

This is a 2D top-down shooter made using the Godot engine 4.6.2.

Current release version: 0.2.0

I followed a tutorial on YouTube on how to make a 2D top-down shooter, but since the tutorial is outdated and I want to scale, I am adding my own stuff too. The tutorial can be viewed [here](https://www.youtube.com/watch?v=HycyFNQfqI0). The tutorial serves as the skeleton over which I built the rest of this game.

All assets and work are my own unless stated otherwise.
